# Module 4: Evaluation, Observability and Production

Welcome to Module 4 of Production AI Agents for Generative Media! This week we make it production-ready: prove what the system costs, how good it is, and when it is safe to ship.

## Learning Objectives

By the end of this module, you will be able to:

* Evaluate generative systems at three layers: system, agent, media — using judges, deterministic checks and human eval
* Build a golden set and a regression gate
* Instrument one trace that answers "why $1.83 / why 94 s": traces + metrics + logs, dashboards
* Design a production architecture: auth, secrets, quotas, abuse handling, prompt injection, content safety, isolation, retention, licensing, provenance, reproducibility
* Ship with versioning, canary releases and rollback; make a go/no-go decision against an SLO
